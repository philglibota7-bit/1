# App-Sammlung

Jede App ist eine einzelne HTML-Datei – einfach im Browser öffnen, keine Installation nötig.

| Datei | App | Beschreibung |
|---|---|---|
| `budget.html` | 💶 **Budget** | Haushaltsbuch: Einnahmen und Ausgaben buchen, Ausgaben-Ringdiagramm, 6-Monats-Vergleich, Budget-Ampel pro Kategorie, Sparziele mit Monatsrate, Daueraufträge. Hell- und Dunkelmodus, Export als JSON und CSV. |
| `schulplaner.html` | 🎓 **SchulPlaner** | Hausaufgaben-Verwaltung, Notenrechner mit Schnitt & Ziel-Rechner, Karteikarten-Trainer (Leitner-System), Pomodoro-Lern-Timer mit Wochenstatistik, Stundenplan. Alles wird lokal im Browser gespeichert, Backup per Export/Import. |
| `arcade.html` | 🕹 **Neon Arcade** | 9 Spiele in einer Datei: Snake, Tetris, 2048, Breakout, Neon Flap, Minesweeper, Memory, Simon, Reaktionstest. Mit Highscores, Sounds und Touch-Steuerung. |
| `jarvis.html` | 🤖 **Jarvis** | Sprach-Assistent mit 3D-Weltkarte und Routenplaner. |
| `bodyscan.html` | 📏 **FitScan** | Kamera-Körperscan mit Maß-Ermittlung und Produkt-Finder. |
| `ip-rechner.html` | 🌐 **IP-Rechner** | Subnetting, IPv6 und Taschenrechner. |
| `fussball.html` | ⚽ **Fußball** | Interaktive Fußball-Website mit Effekten und Spielen. |
| `index.html` | 💌 **Galaxie-Karte** | Animierte Grußkarte mit Galaxie-Effekten. |
| `primus-ot.html` | 🏭 **Primus OT** | Website Primus Oberflächentechnik. |
